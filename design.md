# Project Scope

## 1. Project Goal

The goal of this project is to develop a system that enables users to explore, analyze, and visualize historical data in order to identify patterns, trends, and insights over time.

Specifically, the system aims to support:
- exploration and comparison of disciplinary patterns within Canadian Expeditionary Force (CEF) WWI records
- analysis of offence distributions, demographic trends, and service-related patterns across units, ranks, time periods, and other historical categories

---

**Name:** Canadian Expeditionary Force (CEF) Personnel Files / Service Metadata

**Name:** WWI Courts Martial Records
- **Source:** Statistics Canada
- **Format:** Digitized archival records extracted into structured CSV/database format

### Time Period
- 1914–1918 (First World War)
- Early War: 1914–1915
- Mid War: 1916–1917
- Late War: 1918

---

## 3. System Summary

This project will deliver an interactive historical analysis system focused on Canadian WWI military disciplinary records. The system will allow users to examine courts martial trends, compare patterns across categories such as units, ranks, occupations, birthplaces, and marital status, and explore broader relationships in the data through machine learning–supported analysis.

The platform will include:
- an **Offence Trends** module for viewing aggregate offence patterns over time
- a **Comparative Analysis** module for side-by-side comparison of selected groups
- an **ML Analysis** for clustering, relationship analysis, and outlier detection using multi-feature profiles
- a **Dataset Information** page describing data sources, coverage, and limitations
- a **User Manual** explaining the system modules, offence codes, and interpretation guidance

All analysis will be conducted using aggregated historical data only. The system will emphasize transparency, interpretability, and responsible historical analysis rather than prediction or individual-level inference.
