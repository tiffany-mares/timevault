**Meeting Summary**

* **Purpose:** Brainstorm project approach for the course assignment to build a system that explores historical data sets, visualizes trends, and uses machine learning for pattern discovery.  
*   
* **Available data sets:** historical newspapers, census records, prison records, military records (instructor will provide the actual contents).  
*   
*   
*   
* **Main discussion points:**  
  * Predicting future crime is difficult; focus should be on historical analysis and short-term prediction only if applicable.  
  * Working with a single data set is simpler, but combining two distinct data sets can make the project more interesting and insightful.  
  * Possible project ideas:  
    * Analyze how crime coverage/fear in newspapers correlates with incarceration/prison records and how that varies by region.  
    * Compare health conditions or mortality between prison and military records over time.

  * Timeframe considerations: choosing a bounded historical period (e.g., Cold War era) may yield better, more consistent data.  
  * Deliverable expectations: a searchable system/website with visualizations/infographic-style outputs and transparent/ethical interpretation of findings.  
*   
* **Decisions / tentative plan:**  
  * Narrow initial scope to two data sets (e.g., census \+ prison or census \+ military) to reduce integration complexity, with the option to add others later.  
  * Create a system that supports filtering, comparison, and visualization (infographic-style interface plus search).  
*   
* **Risks / open questions:**  
  * Exact data fields and formats are unknown - will strongly influence which ideas are feasible.  
  * Clarify whether external datasets may be added or if only instructor-provided data must be used.
